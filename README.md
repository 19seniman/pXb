🧧Feature: On-chain transactions using the li.fi DEX, supporting the $Base and $HyperEVM networks to qualify for airdrop rewards.

Note: Before using this script, ensure you have a balance of $USDT on the HyperEVM network worth IDR 2,000.

Install script On Termux / vps

```
git clone https://github.com/19seniman/pXb.git
```

```
cd pXb
```

```
npm install dotenv
npm install ethers
```

```
nano . env
```
( save ctrl + x + y)

Run Script 

```
node lim.js
```
